# Data

This project uses Federal Election Commission candidate summary data covering election cycles from 2008 to 2022.

The original coursework used the following public dataset:

https://www.ics.uci.edu/~algol/teaching/s2022-IV/fec_2008-2022.csv

The dataset contains 26,828 rows and 50 columns describing candidate-level campaign finance information.

## Data Usage

The analysis focuses primarily on:

- candidate party affiliation
- candidate office
- election cycle
- total receipts
- total disbursements

The dataset itself is not stored in this repository. The R scripts load the data from the documented source so the analysis can be reproduced without committing the raw CSV file.
