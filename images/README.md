# Visualizations

This directory contains figures generated by the R scripts in this repository.

## Exploratory Analysis

* `candidate_records.png`: Candidate records by office and party
* `receipts_by_year.png`: Total campaign receipts by party across election years
* `receipt_distribution.png`: Distribution of candidate receipts by party using a log transformation

## Visualization Ethics Case Studies

### Case Study 1: Campaign Receipts Over Time

* `correct_receipts_by_party.png`: Median campaign receipts using the complete 2008-2020 period and a zero-based y-axis
* `misleading_receipts_by_party.png`: Intentionally misleading version using a selective time window and truncated y-axis

### Case Study 2: Receipts vs. Disbursements

* `correct_receipts_vs_spending.png`: Relationship between receipts and disbursements using log scales and uncertainty information
* `misleading_receipts_vs_spending.png`: Intentionally misleading version using top-quartile filtering, linear scales, removed uncertainty, and attention-directing color

The misleading visualizations are included only to demonstrate how analytical and design choices can change the interpretation of the same underlying data.
